2. Описание сервиса

Мобильное приложение KekeevBBQ предоставляет пользователям возможность:

  • просматривать меню ресторана
  • оформлять заказы на блюда и напитки
  • указывать адрес доставки
  • получать уведомления о статусе заказа
  • оплачивать заказ доступными способами

Сервис предназначен исключительно для оформления заказов в ресторане KekeevBBQ.

4. Оформление заказа

При оформлении заказа пользователь:

  • выбирает блюда из меню
  • указывает адрес доставки
  • подтверждает заказ

После подтверждения заказа он передается в обработку ресторану.

Ресторан оставляет за собой право отменить заказ в случае:

  • отсутствия выбранного блюда
  • невозможности доставки
  • ошибки в стоимости заказа

5. Оплата

Пользователь может оплатить заказ следующими способами:

  • наличными при получении
  • переводом денежных средств
  • через платежный сервис FinikPay

Обработка онлайн‑платежей осуществляется сторонним платежным провайдером.

Приложение KekeevBBQ не хранит данные банковских карт пользователей.

6. Доставка

Доставка осуществляется по указанному пользователем адресу.

Срок доставки может зависеть от:

  • загруженности кухни

  • расстояния до адреса доставки

Указанное в приложении время доставки является ориентировочным.
